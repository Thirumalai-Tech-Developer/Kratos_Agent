### 1. Architectural Purpose & Overview

`chat_model.py` provides the LangChain-compatible `BaseChatModel` implementation (`BrainChatModel` / `OmnirouteChatModel`). It allows Kratos' autonomous execution loop, agent chains, and LangGraph components to interface with any OpenAI-compatible provider seamlessly.

Crucially, it incorporates **Model Defense & Sanitization Layers**:
1. **Command Payload Sanitization**: Strips backticks, JSON wrapper artifacts, and shell prefixes generated by small or quantized models.
2. **Path Sanitization**: Corrects string prefix artifacts (e.g. `r"..."`, `f"..."`, `b"..."`) emitted in file path tool arguments.
3. **Resilient Fallback Tool Extraction**: When models output tool calls as plaintext or malformed JSON instead of native API tool calls, an AST- and regex-based extraction pipeline parses the intended tool name and arguments.

### 2. Standalone Sanitization & Extraction Functions

#### `_clean_command_payload(cmd_str: str) -> str`
Sanitizes terminal command strings by removing formatting noise.
- **Parameters**: `cmd_str` (`str`) - The raw command argument emitted by the model.
- **Returns**: `str` - Cleaned, directly executable shell command.
- **Operations**:
  - Extracts commands from enclosed backticks: `` `npm install` `` -> `npm install`.
  - Strips leading and trailing backticks, braces, and quotes.
  - Strips JSON wrapper prefixes like `command: "dir"` -> `dir`.

---

#### `clean_file_path(fp_str: str) -> str`
Cleans file paths from Python literal prefixes and quote artifacts.
- **Parameters**: `fp_str` (`str`) - Raw file path argument.
- **Returns**: `str` - Normalized clean file path.
- **Operations**:
  - Removes raw string indicators: `r"C:\test"` -> `C:\test`.
  - Strips extraneous bounding quotes and whitespace.

---

#### `_fallback_extract_tool_call(text: str) -> dict[str, Any] | None`
Recovers structured tool calls from broken JSON or freeform text when standard JSON parsing fails.
- **Targeted Tools**:
  - `edit_file`: Extracts `file_path`, `target_text`, and `replacement_text`.
  - `write_file`: Extracts `file_path` and multi-line `content`.
  - `run_terminal_command`: Extracts shell `command`.
- **Returns**: `{"name": str, "args": dict}` or `None`.

---

#### `extract_tool_calls_from_text(text: str) -> list[dict[str, Any]]`
Comprehensive scanner identifying structured JSON tool calls embedded within markdown code blocks or raw model generation text.
- **Returns**: List of parsed tool call dictionaries.

### 3. Class: `BrainChatModel` (alias: `OmnirouteChatModel`)

Inherits from `langchain_core.language_models.chat_models.BaseChatModel`.

#### Configuration Properties
- `model_name` (`str`): Target model identifier (e.g., `gemini-3.7-flash-high`, `deepseek-chat`).
- `endpoint_url` (`str | None`): Chat completions endpoint URL.
- `temperature` (`float`, default: `0.0`): Sampling temperature for deterministic tool execution.
- `max_retries` (`int`, default: `2`): Max retries on gateway errors.
- `timeout` (`float | None`): Timeout in seconds.
- `streaming` (`bool`, default: `True`): Whether to stream generation chunks.

#### Core Methods

##### `_generate(messages, stop=None, run_manager=None, **kwargs) -> ChatResult`
Executes synchronous generation.
1. Converts LangChain messages (`HumanMessage`, `AIMessage`, `SystemMessage`, `ToolMessage`) to standard dicts.
2. Invokes `BrainClient.generate()`.
3. Checks for native tool calls or runs `extract_tool_calls_from_text()` fallback.
4. Returns a `ChatResult` wrapping an `AIMessage` with parsed `tool_calls`.

##### `_stream(messages, stop=None, run_manager=None, **kwargs) -> Iterator[ChatGenerationChunk]`
Executes streaming generation via SSE.
1. Yields `ChatGenerationChunk` instances with delta tokens.
2. Accumulates tool call fragments across streaming chunks and surfaces them to LangChain callback handlers.

##### `bind_tools(tools, **kwargs) -> BrainChatModel`
Binds tools (functions, schemas, or LangChain `BaseTool` instances) to the model for tool-calling prompts.
