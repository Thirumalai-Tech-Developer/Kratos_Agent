# Grill a plan

Use when the user explicitly asks for `grill-me`, or asks to challenge a plan before implementation.

1. Read the relevant project files first; answer factual questions from evidence instead of asking the user.
2. List unresolved decisions, their dependencies, and the cost of getting each wrong.
3. Ask concise questions in dependency order. Give a recommended answer with each question and explain the trade-off briefly.
4. Ask only decisions that materially change scope, behavior, architecture, or acceptance criteria.
5. Summarize the settled decisions and remaining assumptions. Stop there unless the user also asked to implement.

Do not use this as a reason to delay clear, already-authorized work or repeat questions the user has answered.
