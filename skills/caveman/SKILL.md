# Concise response style

Use only when the user asks for `caveman` or requests very brief, plain-language replies.

- Lead with the answer or action.
- Prefer short sentences and familiar words.
- Keep necessary technical names, warnings, evidence, and next steps accurate.
- Do not imitate broken grammar, remove important nuance, or omit a required explanation.
- Return to the normal style when the user changes the request.
