# Kratos Universal Computer-Use Engine

## 1. Overview
The Kratos Universal Computer-Use Engine provides cross-platform, autonomous computer operation for Windows 10/11 and Linux (X11 / Wayland).

The core principle:
> **Kratos understands the computer as an environment containing objects, applications, windows, controls, files, processes, and state—NOT primarily screen coordinates.**

## 2. Interaction Priority Ladder
Actions always attempt execution through the strict priority hierarchy:
1. **Native Application API**: OS and process controls
2. **Accessibility API**: Windows UI Automation (UIA) & Linux AT-SPI
3. **Browser DOM**: Playwright & Chrome DevTools Protocol (CDP)
4. **Semantic UI Elements**: High-confidence role/name resolution
5. **Keyboard Navigation**: Native shortcuts and key sequences
6. **Application-Specific Automation**: Dedicated adapters (Chrome, VS Code, Explorer, Notepad)
7. **Vision Grounding**: Visual scene understanding and OCR
8. **Coordinate Mouse**: Lowest-priority fallback

Coordinates are never hallucinated or directly generated by the LLM.

## 3. Closed-Loop Execution Loop
Every action follows the closed-loop cycle:
```text
OBSERVE → UNDERSTAND → PLAN → ACT → OBSERVE → VERIFY → SUCCESS / RECOVER
```

## 4. Multi-Tier Recovery Engine
If an action encounters a failure:
* **Attempt 1**: Semantic UI matching
* **Attempt 2**: Refresh state & re-resolve
* **Attempt 3**: Keyboard navigation (Enter, Escape, Tab)
* **Attempt 4**: Application adapter shortcuts
* **Attempt 5**: Vision grounding
* **Attempt 6**: Coordinate fallback
